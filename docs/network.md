# Network & Services

The following services will be available at the event:

- :material-ethernet: Internet Access via standard 1Gb ethernet 
- :material-earth: Publicly routable IPv4 and IPv6 space (hopefully)
- :material-wifi: _Some_ WiFi
- :material-phone-classic: Copper phone lines, over a TDM core
- :material-phone-in-talk: Real _56k_ Dial Up Internet 
- :material-router-network: VDSL / ADSL
- :material-cellphone-wireless: A DECT network for your cordless phones
  
  
And with ***your*** help, perhaps we'll see some of the following:
{: style="margin-top: 2em;" }

- :material-web: Internet Exchange / ISP
- :material-sync: Token Ring / FDDI
- :material-cable-data: 10BASE2 (Thinnet) / 10BASE5 (Thicknet)
- :material-lan-connect: Acorn Econet / AUN 
- :material-connection: SHDSL / EFM
- :material-radio-tower: Packet Radio
- :material-radio-handheld: Amateur Radio
- :material-television-classic: Cable Television
- :material-television-guide: Teletext
