# Help Us

## Volunteer

We will need volunteers to help set up and take down, and to make sure things run smoothly during the event. A "shift" during the event should be no more than a couple of hours so you get time to enjoy the event.

We'll start organising this a little closer to the time.

## Sponsorship

At this point in time we're not looking for a _financial_ sponsor, however we do need to solve the following problems:

- Power Distribution - Distributing 13A sockets to tables
- Tables & Chairs - It's TBC if the venue will have enough
- Selling Tickets - A hosted platform, without a huge mark up.
- Stationary - Wristbands / Name Badges / Banners etc
- Merchandise - Printed T-Shirts?

If you can help, please [get in touch](contact.md).
